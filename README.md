# FinSight AI (Project Foundation)

Production-ready project foundation for a fintech web application.

## Tech Stack
- Frontend: React (Vite), Tailwind CSS, React Router
- Backend: Node.js, Express, MongoDB (Mongoose)

## Run
1) Backend (MongoDB required)
- Copy `.env.example` to `.env` in `backend/`
- Ensure MongoDB is running
- Start backend:
  - `npm run backend`

2) Frontend
- Start frontend:
  - `npm run frontend`

Or run both:
- `npm run dev`
